# Qué hace cada pantalla

Esta guía describe las funcionalidades de la app desde el punto de vista del asistente al congreso. No requiere conocimientos técnicos.

## 1. Inicio

La pantalla principal que el asistente ve al abrir la app.

Muestra:

- **Destacados**: las novedades más relevantes del congreso.
- **Keynote speakers**: los ponentes principales con foto y nombre.
- **Noticias**: avisos y anuncios del organizador.
- **Actividades sociales**: eventos paralelos al programa académico.

Desde esta pantalla se puede abrir el buscador pulsando la lupa de la barra superior.

## 2. Búsqueda

Pantalla de búsqueda que se abre sobre cualquier otra pantalla.

El asistente puede buscar por título de presentación, nombre de ponente o sala. Los resultados aparecen en tiempo real mientras escribe. También permite filtrar por tipo de contenido (presentación, evento, ponente).

## 3. Programa

Lista de presentaciones de una franja horaria concreta.

Al pulsar una franja del programa, se despliega la lista de todas las presentaciones que se celebran en ese momento, agrupadas por sala. Cada presentación muestra la sala, el horario y los ponentes. El asistente puede marcarla como favorita directamente desde esta lista o abrirla para ver el detalle completo.

## 4. Detalle de presentación

Información completa de una presentación.

Incluye título, sala, horario y duración, ponentes con su institución, resumen del contenido (abstract), etiquetas temáticas y enlaces externos si los hay. El asistente puede guardarla como favorita con el botón de marcador.

## 5. Mi agenda

Lista personal del asistente con todos sus eventos y presentaciones favoritos.

Los elementos aparecen ordenados cronológicamente y agrupados por día. Si el asistente elimina un favorito, desaparece de esta lista. Si instala una nueva edición del congreso, los favoritos del programa anterior se eliminan automáticamente (las notas del diario se conservan).

## 6. Diario

Diario personal del asistente, accesible durante el congreso.

Combina un calendario con la lista de notas escritas ese día. El asistente puede añadir notas de texto con una etiqueta de ánimo (positivo, neutro, negativo). Puede navegar entre días deslizando horizontalmente o pulsando en el calendario. Las notas se conservan entre ediciones del congreso.

## 7. Ajustes

Preferencias personales de la app.

| Sección        | Qué permite                                                      |
| -------------- | ---------------------------------------------------------------- |
| **Apariencia** | Cambiar el tamaño del texto y el tema visual (claro / oscuro)    |
| **Idioma**     | Selección de idioma (en preparación)                             |
| **Datos**      | Recargar los datos del congreso o borrar los favoritos guardados |
| **Acerca de**  | Información sobre la versión de la app                           |
